name: cds-ads
description: Requests data from the Copernicus Climate Data Store (CDS) and Atmosphere Data Store (ADS), operated by ECMWF, with the cdsapi Python client. Use when a task mentions ERA5 or ERA5-Land reanalysis, historical weather, climate normals, seasonal forecasts, CAMS air-quality or atmospheric-composition forecasts (PM2.5, ozone, dust, aerosols), dataset ids, request JSON, the CDS queue and request limits, ~/.cdsapirc setup, or licence acceptance errors. Falls back to ECMWF Open Data and tells the user what a CDS/ADS key would unlock when no credentials are found.
compatibility: Skill instructions are provider-neutral. Scripts need Python 3; request scripts use uv (PEP 723 inline dependencies, cdsapi) and network access to cds.climate.copernicus.eu and ads.atmosphere.copernicus.eu.
